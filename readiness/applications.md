# Applications: concrete implementation inventory

Audit date: 17 October 2026. Source revision: `faddacfc3b5e7cf3a74adfd0efcf8a17e277540b` (clean application checkout). This inventory distinguishes working implementation, registration, test source, and observed execution. **Production operation was not verified for any application in this audit.** No live model, paid provider or deployment operation was invoked.

The [default registration](https://github.com/intochat/digitalbrain/blob/faddacfc3b5e7cf3a74adfd0efcf8a17e277540b/src/DigitalBrain.OS/DigitalBrain.OS/OsApps.cs) names exactly **15 apps**. The feature tree has **20 app manifests**: 17 under `features/os`, three under `features/intochat`. A feature folder is a loadable bundle, not proof that it is installed in an existing account. Creation installs defaults individually through AppInstaller, skips an already-present app, logs an individual installation failure and continues. Circle brains skip the personal defaults.

## How to read the evidence

All source paths below are relative to [the audited source tree](https://github.com/intochat/digitalbrain/tree/faddacfc3b5e7cf3a74adfd0efcf8a17e277540b). Each folder's `app.cs` declares its manifest, operations, settings and connection slots; listed siblings contain executable behavior. This is not a claim that scenario prose in a manifest has passed.

**J** means `src/DigitalBrain.OS/DigitalBrain.OS.Tests.E2E/ShippedAppJourneys.cs`, called by `ShippedAppFacts.FolderAppRunsInTheHeadlessBrowser`. Its switch contains a distinct journey for all 20 apps. The precise assertion scope is recorded below. These browser tests were **not executed in this audit**. **U** means `src/DigitalBrain.OS/DigitalBrain.OS.Tests.Unit/`. That suite was blocked at restore by the package advisory described in [verification](verification.md), so referenced U files establish test implementation, not a passing result. `FeatureCompileFacts.EveryFeatureScriptCompilesInTheRealSandbox` and `TheShippedFeaturesHaveTheShape` cover the full feature directory in source, also not executed successfully here. The passing **264 Apps tests** exercise shared app machinery and fixtures, not every shipped application's real provider path. The selected **11 Flutter tests** cover navigation/root/link behavior only.

## Coverage boundary

Every directory containing `features/**/app.cs` is represented above. Icons and prompts are supporting assets, not extra applications. Runtime generation, publication, storage, sandbox and UI components are covered in [runtime inventory](runtime-inventory.md). Test implementation, passed fixture tests, live browser behavior and production evidence remain separate statuses throughout.
