    details: An app is a specification, a manifest and compiled behaviors. A brain is the ownership scope that holds a person's apps and state.
  - title: C# sandbox
    details: Scripts and generated code run in a separate sandbox image, away from the kernel.
  - title: Flutter shell
    details: A renderer-agnostic UI protocol drives a Flutter desktop shell and a web image.
  - title: Open source
    details: MIT licensed. NuGet packages and container images are published from the intochat/os repository.
